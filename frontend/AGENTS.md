# Frontend Instructions

- Use functional React components and current React Query/API client conventions.
- Keep API calls out of presentation components; preserve shared loading and error behavior.
- Reuse Tailwind tokens and existing components before adding new patterns.
- Treat responsive layout, keyboard access, focus visibility, form labels, contrast, loading, empty, error, and offline states as correctness requirements.
- Do not display raw provider errors, secrets, private ticket content beyond the authorized view, or unsafe HTML.
- Add or update Vitest coverage for changed behavior and run the production build.
